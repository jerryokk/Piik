## Start using Piik

<div class="guide-task-index">

- **[Watch a friend](./getting-started.md#join-a-friends-room)**<br>
  Open an invitation in a computer or phone browser. No installation needed.
- **[Share my screen](./getting-started.md#share-with-piik-app)**<br>
  Run Piik App for Windows, choose a picture and send an invitation.
- **[Use my group's Piik site](./getting-started.md#use-app-with-an-existing-site)**<br>
  Open that site in Piik App and host your room there.

</div>

## Get help

- **App, sharing or sound problems:** start with the [symptom index](./troubleshooting.md#common-problems).
- **Campus networks, media connections or virtual LANs:** use [network checks](./network.md) to choose a connection option.

Still stuck? Export a diagnostic bundle from Piik App and send it, with your
version, system, browser and reproduction steps, to whoever provides your Piik.
Follow the [reporting steps](./troubleshooting.md#reporting-a-problem) to collect diagnostics.

## Run a site for your group

For a permanent group site, deploy Piik Server on a reachable address with HTTPS
and the required network ports.

- [Deploy Piik Server](../operations/self-hosting.md) from the Windows server package.
- [Keep it running and update](../operations/self-hosting.md#keep-it-running-and-update).
- [Look up configuration settings](../standards/configuration.md).
