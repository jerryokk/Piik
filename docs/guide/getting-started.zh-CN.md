# 第一次用 Piik

[English](./getting-started.md) · 简体中文 · [回到 Piik](../../README.zh-CN.md)

Piik 支持一位房主分享屏幕，最多 20 位受邀观众观看。先选适合你的入口：

| 你想做什么 | 从这里开始 |
| --- | --- |
| 看朋友的画面 | [打开对方的邀请](#加入朋友的房间)，不必安装。 |
| 分享给其他网络的朋友 | [Piik App → 公网邀请](#用-piik-app-分享)，保持 App 运行。 |
| 在你们自己的站点开房间 | [在 Piik App 中打开该站点](#通过已有站点使用-app)。 |

![三个步骤：选择窗口、复制房间邀请、和朋友一起坐上沙发。](../assets/quickstart.svg)

## 加入朋友的房间

1. 用电脑或手机浏览器打开朋友发来的邀请链接。
2. 等待画面出现。如果浏览器没有自动播放，点击 **播放**。
3. 将鼠标移到画面上，或轻点画面，显示播放控制栏。

播放控制栏只改变你自己看到的画面和听到的声音。
全屏、画面显示与音量选项见[播放控制](./sharing.zh-CN.md#播放控制)。

只有四位房间号时，打开同一个 Piik 站点，选择 **加入房间**，按需输入站点口令或房间密码。
无法通过房间号加入，或旧链接失效时，请房主发送当前邀请。

各自用 App 创建的本地房间／公网邀请属于不同站点，不能在自己的 App 页面输入对方的房间号。
加入朋友时，直接打开对方的完整邀请链接即可，不必在自己的 App 中创建房间。

## 用 Piik App 分享

1. 向提供 Piik 的人获取 Windows x64 的 **Piik App** 程序包（`piik-app-windows-amd64`），
   完整解压并保留目录结构。
2. 打开 `piik-app.exe`。启动页显示在 App 窗口中，房间也在同一窗口中打开。
3. 邀请不在同一局域网的朋友时，选择 **公网邀请**，再点击 **进入 Piik**。
   其他模式的用途见下方说明。
4. 点击 **开始分享**，按可用选项选择 **摄像头**、**程序 / 窗口** 或 **屏幕**，
   然后选定要分享的画面与声音。
5. 复制房间邀请发给朋友。分享期间保持 App 打开。

### 选择 App 模式

![App 模式选择：已选中公网邀请，也可以选择本地房间。](../assets/guide/app-modes.zh-CN.png#gh-light-mode-only)
![App 模式选择：已选中公网邀请，也可以选择本地房间。](../assets/guide/app-modes.zh-CN.dark.png#gh-dark-mode-only)

- **公网邀请：** 给异地朋友发一个临时网页链接。需要互联网连接，关闭 App 后链接失效。
- **本地房间：** 朋友在同一局域网或虚拟局域网，对方需要能连接到你的电脑。
  多网卡时，可展开 **局域网邀请地址**，选择朋友所在的网络。

本地房间和公网邀请可展开 **站点口令** 设置可选的访问口令。
本地邀请使用 HTTPS；首次访问时，先与房主的 App 核对本地证书，再继续进入，
操作见[证书确认说明](./troubleshooting.zh-CN.md#本地-https-证书提示)。

<details>
<summary>回到启动页或更换模式</summary>

房间服务启动后，点击右上角已就绪的 **App**，可回到启动页管理授权或重新进入房间。
更换本地房间／公网邀请模式时，关闭 App 窗口并重新打开 App 后选择。
这会结束原有房间，公网邀请地址也会重新生成。

### 通过已有站点使用 App

使用朋友或管理员提供的 HTTPS Piik 站点。自行搭建时，按[自部署指南](../operations/self-hosting.zh-CN.md)操作。

1. 在 App 启动页输入站点地址，点击 **打开站点**，无需选择房间模式。
2. 核对站点网址，确认该站点的 App 访问权限，站点会在 App 窗口中打开。
   如果站点要求口令，先输入口令。
3. 点击 **开始分享**，选择 **程序 / 窗口** 或 **屏幕**，
   选好来源后，将新房间的邀请链接发给朋友。

站点负责房间与邀请，App 提供采集。
如果管理员已启用 SFU 转发，房主可在开始分享前关闭 **隐私模式**，允许使用这条兜底线路。

已授权站点与启动收藏可在[App 启动页管理](../../crates/piik-app/README.zh-CN.md#已授权站点)。
画面连不上时，查看[网络排查指南](./network.zh-CN.md)。

### 版本升级

App 与它提供的站点来自同一个 Piik 构建。请按[升级步骤](../../crates/piik-app/README.zh-CN.md#升级)
一起替换；不同构建的 App 与页面会互相拒绝工作。
